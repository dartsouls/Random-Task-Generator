# Random Task Generator

**Автор:** Артем Садовский

## Описание

Программа случайным образом выбирает задачу из списка. Можно добавлять свои задачи с категориями (Учёба, Спорт, Работа). Все сгенерированные задачи сохраняются в историю. Есть фильтр по категориям.

## Как запустить

1. Убедитесь, что Python установлен
2. Скачайте файл `main.py`
3. Откройте терминал в папке с файлом
4. Выполните команду:
   ```bash
   python main.py
